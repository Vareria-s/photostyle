Подключение ФотоСтайл к Avito

1. Откройте https://github.com/Vareria-s/photostyle/settings/secrets/actions
2. Нажмите New repository secret и сохраните первый ключ:
   Name: AVITO_CLIENT_ID
   Secret: персональный Client ID владельца вашего аккаунта Avito.
3. Ещё раз New repository secret:
   Name: AVITO_CLIENT_SECRET
   Secret: соответствующий Client Secret.

Значения не отправляйте в чат и не помещайте в файлы проекта.
Других полей, таблиц, JSON или ручных флагов запуска нет.

Следующий часовой запуск всё проверит автоматически. Чтобы начать сразу:
GitHub → Actions → PhotoStyle Avito hourly snapshot → Run workflow.

Ход подключения виден в Actions. Отсутствующий доступ к автозагрузке,
неполная прежняя выгрузка, недостаточные товарные данные или ошибка Avito
показываются как конкретное препятствие. Это не просьба вручную создавать
конфиг: технический агент разбирает причину. Пока Avito обрабатывает файл
по своему расписанию, подключение не объявляется завершённым.

Неоднозначные или неполные новые товары исключаются;
успешная обработка не означает перенос всего каталога. Счётчики и причины:
https://photostyle-avito.pages.dev/report.json

Обновлять access token вручную не нужно: сервис получает новый автоматически
из этой пары ключей. Если один ключ сохранён без второго, запуск остановится.
