# Документы PhotoStyle

Оригинальные инструкции, сертификаты и декларации, подобранные для товаров PhotoStyle.

По состоянию на 27 ноября 2026 года:

- В этом переносе опубликовано **1129 уникальных PDF**, около **8,38 ГБ**.
- Документы найдены для **1010 из 1230 позиций**.
- Ссылки добавлены во вкладку «Документы» **992 существующих карточек** нового сайта Tilda.
- Для 18 позиций с документами карточки Tilda пока не сопоставлены.

## Где хранятся файлы

PDF размещены в [GitHub Releases](https://github.com/Vareria-s/photostyle/releases), в выпусках `documents-2026-11-26-01`, `documents-2026-11-26-02` и `documents-2026-11-27-03`. Две пробные инструкции Canon находятся в отдельном выпуске `canon-g7x-mark-iii-v1`.

Имя `doc-<SHA-256>.pdf` определяет содержимое файла. Один PDF может использоваться для нескольких подходящих моделей.

[Итог проверки публикации](publication-status.json) включает размер, SHA-256 и ссылку каждого PDF. Два файла после неудачного повторного скачивания у источника загружены из ранее сохранённых оригиналов и отмечены отдельно. Сохранены исходные файлы без сжатия или изменения содержания.

## Просмотр в карточке

На [новом сайте PhotoStyle](https://hundred-wintry-emerald.tilda.ws/) ссылки из вкладки «Документы» открываются во встроенном PDF.js. Бесплатный проект Cloudflare Pages `photostyle-documents.pages.dev` обслуживает просмотрщик и передаёт PDF из этого репозитория с заголовком для открытия в браузере. Сам архив PDF хранится в GitHub Releases.

Обработчик принимает только файлы из этого репозитория, поддерживает частичную загрузку PDF и не является прокси для произвольных адресов. Spaceweb и сайт йоги не используются.
